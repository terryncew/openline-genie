Genie RC6 — Owner Walkthrough

Start

  1. Open a terminal.
  2. Run cd into the directory where you extracted the release archive (the folder containing genie_server.py)
  3. Run python3 genie_server.py --port 8795 --state-dir /tmp/genie-state
  4. Open http://127.0.0.1:8795/ in a browser.
  5. Leave the terminal window open while you use the page.

Figures shown are planning-model projections, not real earnings. Nothing you try can lose your accepted project unless you accept a change.

Try it

  1. Type Help me build a neighborhood bakery. in the box.
  2. Click Build.
  3. Wait until the build finishes.
  4. Tap a part of the picture.
  5. Tap anything that looks interesting.
  6. Try changing something.
  7. Tap "Accept this change" to keep one.
  8. Tap "Reject this change" to discard one.
  9. Tap "STOP / Freeze".
  10. Tap "Clear STOP".
  11. Tap "Close", then tap "Reopen".
  12. Tap "Export app" at the top.

Stop

  1. In the terminal, press Ctrl+C.
  2. Close the terminal window.

If something looks wrong

Tap "STOP / Freeze". Note what you tapped just before it. Tell Muse.
